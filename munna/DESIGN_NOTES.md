# v23 design / interaction notes

The direction is intentionally not a direct visual copy of any reference.

## Interaction principles used

- **Bruno Simon portfolio:** make interaction part of the experience rather than decorative UI. Munna now reacts to hover/search/feedback/touch, surfaces speech, and visibly performs DJ work while audio plays.
- **Audio-visualization references:** use synchronized, real-time visual motion. The room signal is a lightweight Canvas visualizer whose motion/state changes during preview playback.
- **Music-product principle:** keep navigation compact and let music/player/character behavior dominate the screen.

## Visual direction

- deep midnight background rather than bright white/paper
- high-contrast character and booth lighting
- compact top navigation, no left navigation rail
- vivid coral / cyan / violet / lime accents used sparingly
- Bricolage Grotesque for expressive UI typography and DM Mono for technical/status microcopy
- one compact sticky DJ broadcast window rather than a full-height horizontally stretched rail
